# TE 255 / COE 4040 — Problem Solving Using MATLAB

MATLAB source code for the course (KNUST). This repository holds **code** —
`.m` scripts, functions, and small datasets used in lectures and assignments.

Course materials that are not code — lecture slides, assignment briefs,
textbooks, and other resources — are distributed to students separately and
are intentionally **not** kept under version control here.

## Layout (suggested)

```
scripts/      reusable example scripts shown in lectures
solutions/    reference solutions for coding assignments
data/         small datasets used by the scripts
```

Add code as the semester progresses.
